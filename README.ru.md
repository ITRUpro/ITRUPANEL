## О проекте

**ITRUPANEL** превращает чистый Linux-сервер в хостинг-платформу. У каждого сайта свой системный пользователь и свой пул
PHP-FPM, поэтому сайты изолированы друг от друга. Всё управляется из браузера, на русском или английском, в светлой или
тёмной теме. Панель — один бинарный файл на Go с встроенным интерфейсом.

Панель **бесплатна для личных и коммерческих задач**, в том числе для хостинга своим клиентам, и распространяется под
лицензией [GNU GPL v3](LICENSE.txt).

## Возможности и службы

| Раздел | Что внутри |
| --- | --- |
| **Сайты** | Nginx + PHP-FPM, статика, обратный прокси, свой пользователь и версия PHP у каждого сайта, алиасы, кириллические домены, редиректы, gzip, свои директивы Nginx, сайт по умолчанию, при необходимости Apache или OpenLiteSpeed |
| **PHP** | Несколько версий PHP одновременно, модули, редактор `php.ini` |
| **Базы данных** | Базы и пользователи MariaDB, phpMyAdmin, импорт и экспорт дампов, доступ по IP, дополнительные серверы MySQL/MariaDB в Docker |
| **Почта** | Postfix, Dovecot, OpenDKIM, антиспам Rspamd, веб-почта Roundcube, квоты, алиасы, пересылка, проверка DNS |
| **DNS и SSL** | Зоны и записи BIND, Let’s Encrypt с автоматическим выпуском и продлением, самоподписанные и свои сертификаты |
| **Файлы и FTP** | Файловый менеджер с редактором кода (подсветка, поиск и замена), корзина, пользователи Pure-FTPd |
| **Резервные копии** | Файлы, базы и настройки; полные и инкрементные цепочки; на сервере, на FTP или в облаке — Яндекс.Диск, Облако Mail.ru, Dropbox, Google Drive, любой WebDAV (Nextcloud, ownCloud) или S3-совместимое хранилище (Amazon S3, Yandex Object Storage, Cloudflare R2, Wasabi, DigitalOcean Spaces, MinIO), отдельно или вместе с сервером; просмотр копии и восстановление только нужного |
| **Импорт данных** | Перенос сайтов, баз, почты (с письмами и паролями), DNS-зон, FTP-пользователей, cron и настроек копирования с другого сервера ITRUPANEL по адресу панели и логину администратора; с **FASTPANEL** по SSH (сайты, базы, FTP-пользователи и почта с прежними паролями, письма, cron); с любого другого сервера по SSH (сайты, базы, cron) |
| **Docker** | Контейнеры, проекты Compose, образы, сети, тома, очистка |
| **Безопасность** | Ограничения запросов для каждого сайта, защита входа и Fail2ban для FTP, двухэтапная аутентификация (TOTP) и доступ к панели только с выбранных IP-адресов, брандмауэр входящих соединений, антивирус с необязательным ClamAV, карантин и лечение из резервных копий |
| **Мониторинг** | Дашборд, история ресурсов, трафик по сайтам, использование диска, журналы сайтов, журнал операций, задачи, уведомления |
| **Администрирование** | Терминал root в браузере, планировщик CRON, перезагрузка сервера, обновления панели в один клик с подписанными выпусками, по желанию автоматические (по умолчанию выключены) |

Подробно о каждом разделе — в [документации](https://itrupanel.com/docs.html).

## Антивирус

Раздел **«Антивирус»** проверяет сайты на веб-шеллы и вредоносный код и умеет лечить заражённые файлы.

- **Встроенная проверка**, доступна сразу, без установки пакетов: веб-шеллы, выполнение закодированного кода, вредоносные вставки в PHP, JS и `.htaccess`, PHP-код в картинках и PHP-файлы в папках загрузок. Закомментированный код угрозой не считается, длинные закодированные строки расшифровываются, чтобы было видно содержимое, а правила подобраны так, чтобы не срабатывать на обычный код WordPress, Joomla и Bitrix
- **ClamAV** (по желанию): проверка по базам сигнатур; базы (около 120 МБ) обновляются раз в сутки, а если официальный сервер недоступен из страны сервера, панель переключается на проверенные зеркала
- **Лечение из резервных копий**: для каждого заражённого файла панель находит в копиях последнюю чистую версию и восстанавливает только этот файл; если чистой версии нет, вредоносная вставка вырезается, а подброшенные файлы уходят в карантин. Перед изменениями показывается план
- **Карантин**: прежние версии изменённых файлов сохраняются и могут быть возвращены
- **Проверка** всех сайтов, одного или выбранных, вручную или по расписанию (каждый день или раз в неделю); в результатах файл, строка, угроза и степень опасности, а о находках сообщают уведомления
- **Бережно к слабым серверам**: проверки никогда не идут одновременно (по одной, а движки по очереди), ClamAV работает с самым низким приоритетом и не запускается на серверах с памятью меньше 2 ГБ, расписание по умолчанию — воскресенье в 04:00

Эвристика может давать ложные срабатывания, поэтому перед удалением подозрительного файла посмотрите находку.

## Установка

От root на новом сервере:

```bash
wget -O install.sh https://itrupanel.com/panel/install-itrupanel.sh && bash install.sh
```

Установщик скачивает выпуск, проверяет контрольную сумму и подпись, настраивает Nginx, PHP-FPM, MariaDB, FTP и DNS и выводит
адрес панели со **случайными логином и паролем администратора**. Откройте `https://IP_СЕРВЕРА:3333` и войдите.

Дополнительные параметры:

```bash
PANEL_LOGIN=имя PANEL_PASSWORD=пароль bash install.sh   # свои логин и пароль
PHP_VERSION=8.4 bash install.sh                         # версия PHP для установки
PHP_VERSION=none bash install.sh                        # не устанавливать PHP
```

Логин и пароль позже меняются в панели (значок ключа) или командой `itrupanel passwd пароль [логин]`.

Порты: панель TCP 3333 · сайты 80/443 · FTP 21 и пассивные 30000–30100 · DNS 53 (если используется) · почта 25/587/993 (если включена).

## Обновление

Та же команда установщика обновляет установленную панель и делает копию программы и настроек. Выпуски — полные архивы с
контрольной суммой SHA-256 и подписью Ed25519, которые установщик и панель проверяют перед обновлением. Обновить можно и кнопкой
**Обновления** в самой панели.

## Перенос с другого сервера

На новом сервере откройте **Импорт данных**, выберите, откуда переносите, и что перенести:

- **ITRUPANEL** — адрес и логин администратора старой панели;
- **FASTPANEL** — адрес сервера и доступ root (или sudo) по SSH; панель читает списки из самой FASTPANEL и переносит сайты, базы, FTP-пользователей, почту с письмами и задания cron с прежними паролями;
- **другой сервер по SSH** (ISPmanager, HestiaCP, aaPanel и другие) — сайты, базы и задания cron.

Недостающие версии PHP ставятся автоматически; перенос работает между Debian, Ubuntu, AlmaLinux и Rocky Linux.

## Сборка из исходников

Нужны Go (версия из `go.mod`) и Node.js 20 или новее.

```bash
git clone https://github.com/ITRUpro/ITRUPANEL.git
cd ITRUPANEL
./build.sh                # bin/itrupanel-linux-amd64 и bin/itrupanel-linux-arm64
go test ./...             # модульные тесты
```

Попробовать интерфейс локально, не трогая систему (в демо-режиме команды не выполняются):

```bash
go run ./src -demo -http -listen 127.0.0.1:3399
```

Интерфейс написан на обычном JavaScript в `src/web/`, английские тексты лежат в `src/i18n/`. Редактор кода — сборка CodeMirror 6 из
`tools/codemirror`.
