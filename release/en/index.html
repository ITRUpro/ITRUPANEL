INSTALLATION

One command.
Ready to get started.

Run the installer in your Linux server’s root terminal. It downloads the archive, verifies its checksum and detects the architecture. Download and extraction use /var/tmp; allow at least 100 MB of free space for the archive.

If ITRUPANEL is already installed, the script updates it and backs up the program and settings. When run from the panel Shell client, the update continues in a separate service after the terminal closes.

Full instructions ↗
root@server:~0.2.9
# Install or update ITRUPANEL
wget -O install.sh https://itrupanel.com/panel/install-itrupanel.sh && bash install.sh

Run on the server as root, without sudo.

Free to use. The panel is provided “as is”. Before installing, read the terms of use.

BEFORE YOU START

Overview
what matters.

Answers about installation, certificates and using the panel.

Why does the browser warn about the certificate?

The panel initially uses a self-signed certificate. In Server information → Panel address and SSL, enter a domain and choose Let’s Encrypt or your own certificate. You can also open the panel without a port there: the address becomes https://domain, and port 3333 can optionally be closed to internet access. Let’s Encrypt requires a DNS record pointing to the public IP and external access on port 80.

Can I install it alongside another panel?

Use a clean server for a new installation: the installer configures nginx, MariaDB, DNS and other shared services. Automatic migration from another panel is not provided.

What is required for mail?

The mail server is installed when you add the first domain in Mail. You need a public IP, DNS records, PTR and a provider that permits port 25. Clients use IMAP 993 TLS and SMTP 587 STARTTLS. Roundcube webmail and Rspamd antispam are switched on per domain. Quotas, forwarding and local aliases are also available there. The domain DNS button shows MX, A, SPF, DKIM, DMARC and PTR, checks records and lets you preview and apply them to the panel’s DNS zones. Webmail opens on the domain’s mail name, for example https://mail.example.com/. IMAP import is not implemented yet.

How does OpenLiteSpeed work?

Select it in site settings. nginx remains the front-end server, OpenLiteSpeed runs behind it, and PHP uses PHP-FPM of the selected version. .htaccess Rewrite rules are supported; restart OpenLiteSpeed after editing them. LSCache is not configured automatically.

How do I configure the firewall?

Open Firewall in the main menu, install the module, create rules and enable filtering. Allow, deny and partial actions using IP lists are available. The first matching rule applies; unmatched connections are allowed. Filters new incoming connections to the server. Other firewall rules are retained and may further restrict access.

What if /tmp is full?

The online installer uses a separate working directory in /var/tmp and removes it on completion. For manual updates, upload and extract the ZIP in your home directory. Using /var/tmp does not free up a full /tmp: move any temporary archives you need to the main disk.

Where can I see the result of a long operation?

Installation and configuration run as background tasks. Tasks shows stages, logs and results. You can close the window and return to the result later.
