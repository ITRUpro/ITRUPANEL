# Code of Conduct

ITRUPANEL is a community project, and we want everyone to feel welcome to ask questions, report problems and send changes —
whatever their experience, language, background or identity.

## Our standards

Expected behaviour:

- be respectful and patient; assume good intentions and explain your reasoning
- give and accept constructive feedback; focus on the problem, not on the person
- write in English or Russian, and help others who are still learning the language or the tools
- keep discussions on topic and use the right place: issues for bugs and ideas, the forum for questions

Unacceptable behaviour:

- harassment, insults, threats, personal attacks or discriminatory language
- publishing someone's private information (addresses, logins, passwords, server details) without their permission
- spam, advertising unrelated to the project, and deliberately disruptive posts
- anything else that would be inappropriate in a professional setting

## Scope

This code applies in the repository (issues, pull requests, discussions, comments) and in other project spaces such as the
[forum](https://itrupanel.com/forum/), and when someone represents the project in public.

## Enforcement

Maintainers may edit or remove comments, lock discussions, close issues and pull requests, and block people who break this code.

To report a problem, write to the maintainers privately through the [forum](https://itrupanel.com/forum/) or use
**Security → Report a vulnerability** if it also concerns security (see [SECURITY.md](SECURITY.md)). Reports are handled in
confidence, and the reporter's identity is not shared.

This code of conduct is inspired by widely used community guidelines such as the Contributor Covenant.
